Software piracy can include unauthorized installers, source-code distribution, cracked applications, license keys, modified packages, or fraudulent download pages. These cases can create revenue, security, and customer-support risk.

## Establish authoritative references

Maintain source-control history, release builds, code ownership agreements, license terms, hashes, signing certificates, and approved distribution channels.

## Assess the reported package

Record the URL, page context, advertised version, uploader, file details, and capture time. Avoid executing unknown software in an uncontrolled environment; malware analysis requires appropriate security procedures.

## Separate relevant issues

A case may involve copyright, trademark, circumvention, leaked credentials, malware, or contract violations. Each allegation should be supported and routed correctly.

## Coordinate legal and security teams

Security may need to assess customer risk and compromised keys while enforcement addresses distribution. Preserve case links and outcomes so repeat domains and actors can be recognized.

Technical evidence improves accuracy, but disputed or high-impact action may require specialist legal review.
